# Azure DevOps Evidence Checklist

The brief requires Azure DevOps use during implementation. Do not invent or backdate evidence. Add real project evidence here or to the final submission document.

Capture:
- project/board name;
- backlog/user stories;
- assigned work items;
- sprint/iteration view;
- task status changes;
- commits or GitHub links attached to work items where available;
- test/bug work items;
- dates showing ongoing use during development; and
- team meeting notes or decisions linked to work.

For each screenshot, include a short caption explaining what requirement it proves.
