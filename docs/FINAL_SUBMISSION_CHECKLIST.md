# Final Task 2 Submission Checklist

## Documentation pack
Prepare a final submission document with:
1. Cover page: project name, module, Task 2, group members/student numbers and submission date.
2. Table of contents/index.
3. GitHub repository link: https://github.com/Kmakoro/MzansiGems
4. Pull-request/Actions evidence.
5. System architecture summary.
6. API/OpenAPI evidence.
7. Database structure screenshots/ERD.
8. Automated test evidence.
9. Physical-phone screenshots.
10. User guide/help evidence.
11. Azure DevOps evidence from the real project history.
12. Demonstration-video link.

## Demo preparation
The final video should visibly demonstrate:
- Android app running on a real phone;
- email/password registration/login;
- Google SSO;
- settings;
- API-backed data changes;
- a change made in Android appearing on the website (and vice versa);
- database records;
- Firebase Authentication user;
- error/validation handling; and
- GitHub Actions/tests.

## External setup that must be completed before calling the project final
- Configure Firebase Authentication and Android SHA-1.
- Configure `FIREBASE_WEB_API_KEY` on the PHP server.
- Use an HTTPS-hosted API/database for the final demonstration if required by the brief.
- Test the exact APK on a physical phone.
- Capture genuine Azure DevOps and meeting evidence.
- Record the final professional video with voice-over.
