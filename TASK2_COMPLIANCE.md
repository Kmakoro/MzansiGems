# Task 2 Compliance Checklist - Mzansi Gem

## Shared mobile/website architecture
Android and website use the same PHP REST API and MySQL database. Firebase is used only for Google authentication on Android, so application data remains synchronized.

## Task 2 coverage
- Native Android app with GUI and input controls.
- Email/password registration and login with PHP password hashing.
- Google SSO through Firebase Authentication on Android.
- Settings menu with profile, preferences, security and account actions.
- REST API documented by OpenAPI and integrated in Android with Retrofit/OkHttp.
- Relational MySQL database with keys, relationships and indexes.
- Unit tests for authentication/input validation.
- GitHub Actions workflow runs unit tests and builds the debug APK.
- Physical-phone networking instructions and development configuration.
- In-app Help & Support plus a user guide.
- Additional simulated records for rubric evidence.

## Evidence still requiring the team's real accounts/devices
- Firebase project configuration and SHA-1.
- Physical Android phone test.
- Hosted API/database evidence for the final demo if required.
- Azure DevOps history/board evidence.
- Final professional demonstration video.
